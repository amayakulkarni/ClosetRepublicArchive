# Content import and fact-check policy

Rules for bringing outside content into https://wiki.closetrepublic.com, and the review every page passes before readers see it.

Members of Closet Republic once hid who they are. A careless page can out someone, give unsafe advice, or spread a wrong legal claim. Privacy and accuracy come before page count.

## 1. Ethical import rules

### Licence

1. Import text only from sources in Tier A of [SOURCES.md](SOURCES.md): CC BY-SA, CC BY, CC0 or public domain.
2. Never import NC (non-commercial), ND (no derivatives) or "all rights reserved" text, even with credit. Write original text and cite the source instead.
3. For MediaWiki sites, the importer reads the site's licence live and stops if it is not on the allowed list. A changed licence stops the import automatically.
4. Images are not imported. Each image has its own licence; add images by hand after checking the file's own licence page (for example its Wikimedia Commons page).

### Attribution

Every imported page keeps a visible "Source and licence" box (the importer adds it) with:

- the source page title and a link to the exact revision copied,
- a link to the source page history, which lists the authors,
- the source licence name and link,
- the date of import, and a note that the page was changed after import.

The history link is the attribution. Contributor usernames are not copied into the wiki: this meets CC BY-SA attribution and keeps volunteer names off the page.

Do not remove the box when editing. If the page is fully rewritten so that no source text remains, keep the source in "Sources and credits" instead.

### Polite collection

1. Prefer, in order: official dumps (Wikimedia dumps, Kiwix ZIM files, a dump requested from the wiki's administrators), then the site's API, then nothing. Never scrape rendered HTML pages.
2. Check `robots.txt` before reading anything. The importer refuses article paths that `robots.txt` disallows for its user agent.
3. Send an honest User-Agent naming Closet Republic and a contact address.
4. One request at a time, at least 2 seconds apart, with `maxlag=5` on MediaWiki. Back off when the server says so (`Retry-After`, HTTP 429 or 503).
5. Import a small batch per run (25 pages by default) so the review queue stays manageable.
6. For a large import from a community wiki, ask its administrators first. Many will provide a dump, and asking builds goodwill.

### Privacy

1. Import only articles (MediaWiki namespace 0). Never import user pages, talk pages, forum threads, edit histories or contributor lists.
2. Never import biographies of living people or lists of "notable people" with an orientation or gender identity. The importer skips pages in categories such as "Living people".
3. Never query Wikidata properties about people's sexual orientation, gender identity or health.
4. The importer removes email addresses and phone numbers it finds and flags the page for review. Public helpline numbers are added back by hand after checking.
5. Never copy posts from the Closet Republic forum, Discord or Reddit into the wiki without the author's explicit, written permission.
6. Use public names only, with permission, for any person named in Closet Republic's own pages.

### Takedown

If an author, archive or person asks for removal, unpublish the page the same day, then discuss. Reports arrive at corrections@closetrepublic.com (linked from the wiki footer).

## 2. Where drafts live

| Path | Who sees it | Purpose |
| --- | --- | --- |
| `drafts/imports/<source>/<page>` | Reviewers only | Raw imports waiting for review |
| `drafts/new/<page>` | Reviewers only | New pages written by members, before review |
| `drafts/review-queue` | Reviewers only | List regenerated by the importer after each run |
| Final paths (see [TAGS.md](TAGS.md)) | Everyone | Published pages |

Imports are always created with **Published** off. On top of that, a page rule denies guests and ordinary members any access to `drafts/`, so a draft stays hidden even if someone ticks "Published" by mistake.

### Groups and page rules (Wiki.js Administration > Groups)

1. **Guests** (built in): add a rule **Deny** `read:pages`, `read:source`, `read:history` on paths that **start with** `drafts/`.
2. **Members** (logged-in readers and editors): same Deny rule on `drafts/`.
3. **Reviewers**: Allow `read:pages`, `write:pages`, `manage:pages`, `read:history` on all paths. Only this group can publish.
4. **Importer** (used only by the importer's API key): Allow `read:pages` and `write:pages` on paths that **start with** `drafts/`; nothing else.

Then in Administration > API Access, turn the API on and create a key for the **Importer** group. Put the key in `.env` as `WIKIJS_API_KEY`.

## 3. Fact-check before publishing

No page goes live without at least one reviewer. Pages about law, health or safety need **two** reviewers, one of whom did not write or import the page.

### Reviewer checklist

The importer adds this checklist to every draft. New pages copy it from the page template.

1. **Licence.** The source box shows an allowed licence and the links work.
2. **Claims have sources.** Every factual claim (dates, numbers, laws, medical statements) has a citation in "Sources and credits". Remove claims that cannot be sourced.
3. **Primary sources for law.** Legal claims are checked against the Act or judgment itself (India Code, Supreme Court or High Court site), not a blog or another wiki. Record the section or paragraph number.
4. **Current.** Check the law or service is still in force and the date of the latest change. Note "As of YYYY-MM" for anything that can change.
5. **India context.** Where a global page says "in most countries", add or link what applies in India.
6. **Health and safety.** No medical advice beyond what a cited clinical body says. Helplines and organisations are checked to be active (call or visit their official site) within the last 3 months.
7. **Privacy.** No private person is named or identifiable; no orientation or identity is attributed to a living person; no screenshots of chats or posts.
8. **Tone.** Plain language; respectful terms; no slurs except where quoting a law or source, marked as a quotation.
9. **Parody line.** Pages about Closet Republic make clear it is a parody micronation, not a government.
10. **Tags and path.** Correct type, region and topic tags (see [TAGS.md](TAGS.md)) and a final path.

### Publishing steps

1. Open the draft, work through the checklist, and edit the text.
2. In the "At a glance" box set **Status** to `Fact-checked`, fill **Fact-checked by** (reviewer's public name or handle) and **Last reviewed** (date).
3. Remove the yellow "Draft: not fact-checked" banner and the reviewer checklist.
4. Remove the tags `needs-review` and `imported-draft`; add `fact-checked`.
5. Page properties > **Path**: move the page from `drafts/...` to its final path.
6. Turn **Published** on and save.
7. For law, health or safety pages, a second reviewer repeats steps 1 and 2 before step 6.

### After publishing

- The importer checks every imported source page on each run. If the source changes after the page was published, the importer **does not** change the published page. It lists the page under "Source changed since review" in `drafts/review-queue`, with a link to the source diff. A reviewer decides whether to update.
- Every published page is reviewed again at least once a year (sooner for law and health). Pages not reviewed for 12 months are listed in the queue as "Due for re-review".
- Readers report possible errors at corrections@closetrepublic.com. A report about safety or privacy is handled the same day: unpublish first, fix, then republish.
